# Auto-Insurance-Risk-Claims-Analysis
End-to-end Auto Insurance Analytics project using Microsoft Fabric and Power BI.

###Project Overview

This project focuses on analyzing auto insurance data to identify customer risk profiles, claim trends, and policy insights using Microsoft Fabric and Power BI. The solution was built using Lakehouse, Dataflow Gen2, Semantic Modeling, and interactive dashboards.

Domain

Insurance Analytics

Tools & Technologies
1) Microsoft Fabric
2) Microsoft Power BI
3) Lakehouse
4) Dataflow Gen2
5) Semantic Model
6) DAX
7) Power Query
8) ETL
9) Data Visualization

Project Workflow
1. Loaded insurance dataset into Microsoft Fabric
2. Created Lakehouse for centralized storage
3. Built Dataflow Gen2 pipelines for ETL and transformation
4. Designed Semantic Model with relationships and measures
5. Developed interactive Power BI dashboards
6. Generated KPIs and business insights for claims and risk analysis

Dashboard Insights
1. Identified high-risk customer segments
2. Analyzed claims based on customer demographics
3. Compared claim trends across vehicle categories and coverage zones
4. Generated insights for insurance decision-making

Skills Demonstrated
Microsoft Fabric, Power BI, Lakehouse, Dataflow Gen2, Semantic Modeling, DAX, Power Query, ETL, Data Visualization, Insurance Analytics
